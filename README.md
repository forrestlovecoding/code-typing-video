# 代码打字机 · 竖版代码打字视频生成器

粘贴一段代码，生成本地运行的**科技感背景 + 打字机效果**竖屏视频（9:16），导出 MP4 后可直接发布到抖音 / 视频号 / B 站 Shorts 等短视频平台。

本地 Web 应用，所见即所得预览，逐帧确定性渲染导出，不依赖任何在线服务。

## 功能特性

- **代码输入**：粘贴代码 / 打开本地文件 / 4 个一键示例（JS / Python / TS / Go）
- **打字动画**：逐字打出 + 闪烁光标；缩进空格瞬间跳过、行尾停顿，节奏接近真人敲代码
- **语法高亮**：基于 Prism.js，支持 16 种语言，颜色随打字进度保持稳定
- **滚动跟随**：光标到达窗口 62% 高度时自动平滑上滚
- **4 种科技背景**：深空粒子网络 / 霓虹极光 / 黑客矩阵代码雨 / 赛博透视网格
- **可调参数**：打字速度、行间停顿、字号（超宽自动适配）、片头/片尾时长、行号、macOS 窗口开关、自定义窗口标题
- **MP4 导出**：WebCodecs 确定性逐帧编码 H.264，1080×1920 或 720×1280，24/30/60 fps，带进度条与取消，速度快于实时播放且不掉帧

## 快速开始

要求：Node.js 18+，浏览器使用 **Chrome 或 Edge**（导出 MP4 依赖 WebCodecs）。

```bash
npm install
npm run dev
```

打开 http://localhost:5188 即可使用。

> Windows 用户也可以直接双击 `start.bat`（或桌面「代码打字机」快捷方式）：自动检测环境、安装依赖、启动服务并打开浏览器。

## 使用流程

1. 左侧粘贴代码，或点击示例按钮 / 打开本地文件
2. 右侧竖屏预览实时播放打字效果，可拖动进度条、暂停、循环
3. 在参数面板调整：背景主题、打字速度、行间停顿、字号、片头片尾、窗口标题等
4. 点击右上角「⬇ 导出 MP4」，等待进度条完成，自动下载视频

> 成片时长实时显示在预览下方；代码视频建议控制在 3 分钟以内，代码长度由用户自行把握。

## 技术架构

```
输入代码 → Prism 分词着色（展平为绝对下标区间）
        → 时间轴构建（每字符显现时刻 + 滚动关键帧，含确定性抖动）
        → 单帧渲染 renderFrame(ctx, w, h, scene, t)   ← 纯函数，t 决定一切
        ├─ 预览：requestAnimationFrame 逐帧绘制到 720×1280 画布
        └─ 导出：1080×1920 逐帧渲染 → WebCodecs H.264 → mp4-muxer → MP4
```

预览与导出共用同一渲染函数，所有动画基于时间 `t` 确定性计算，保证"所看即所得"，导出不掉帧、不依赖实时录制。

## 目录结构

```
src/
├── engine/            # 核心引擎
│   ├── languages.ts   # 语言列表与 Prism 语法注册
│   ├── highlight.ts   # 分词 → 绝对下标着色区间 → 按行切分
│   ├── timeline.ts    # 打字时间轴、滚动关键帧、确定性抖动
│   └── themes.ts      # 4 套主题与调色板
├── render/            # 渲染引擎
│   ├── scene.ts       # 场景构建：度量、字号自动适配、窗口布局
│   ├── backgrounds.ts # 4 种背景绘制器（基于 t 的确定性动画）
│   └── frame.ts       # 单帧渲染：窗口 + 代码 + 光标
├── export/
│   └── exporter.ts    # WebCodecs 逐帧编码 + mp4-muxer 封装
├── components/        # UI 组件
├── samples.ts         # 示例代码
└── App.tsx            # 主界面
```

## 常见问题

- **导出按钮报错提示不支持编码？** 请使用最新版 Chrome 或 Edge 打开，导出依赖 WebCodecs 硬件编码。
- **代码太长怎么办？** 字号会自动缩小以适配宽度；打字速度可调至 40 字/秒加快节奏。
- **视频没有声音？** 首版定位为纯画面视频，配乐请在短视频平台发布时自行添加。
- **为什么预览和导出效果完全一致？** 二者共用同一个纯函数渲染器，逐帧渲染由时间参数驱动，与实时性能无关。
